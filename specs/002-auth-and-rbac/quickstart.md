# Quickstart

Once implemented, the following steps will be required to run the feature:

1. `cd backend && npm install` (to install `better-sqlite3`, `bcryptjs`, and `jsonwebtoken`)
2. `npm run dev` to start the backend server.
3. In a separate terminal, `cd frontend && npm install` (to add context/routing if not already present).
4. `npm run dev` in the frontend directory.
5. Access the application at `http://localhost:5173`.
6. Use the web interface to register a new user, then login.
